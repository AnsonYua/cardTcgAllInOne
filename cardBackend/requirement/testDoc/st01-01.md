
  1. Pair AP boost applies on your turn

  - Setup: Player A has ST01-001 paired with any pilot + another unit. currentPlayer = A, phase = MAIN_PHASE.
  - Action: Run ContinuousEffectManager.processAllContinuousEffects(...).
  - Expect: All A units have continueModifyAP +1. Opponent unchanged.

  2. Pair AP boost not active when unpaired

  - Setup: Same, but remove pilot from the paired slot.
  - Action: Re-run processAllContinuousEffects(...).
  - Expect: No AP boost on A units.

  3. Pair AP boost only on your turn

  - Setup: Same paired state, but currentPlayer = B.
  - Action: Re-run processAllContinuousEffects(...).
  - Expect: No AP boost on A units.

  4. Repair 2 triggers at end of your turn

  - Setup: Player A has ST01-001 with damageReceived >= 2. currentPlayer = A, phase = END_PHASE.
  - Action: Run SBA processing (end‑phase repair check + repair execute).
  - Expect: Damage reduced by 2 (or to 0 if less than 2).

  5. Repair does not trigger on opponent’s end

  - Setup: Same damaged unit, but currentPlayer = B, phase = END_PHASE.
  - Action: Run SBA processing.
  - Expect: No heal on A unit.

  6. AP boost removed after source unit destroyed

  - Setup: Paired ST01-001 + another unit, currentPlayer = A, phase = MAIN_PHASE.
  - Action: Apply effects (confirm boost), then destroy the paired unit (via battle or destroyUnitInSlot), re-run
    processAllContinuousEffects(...).
  - Expect: No AP boost remains.

  
  7. Link allows immediate attack

  - Setup: Player A plays ST01-001 (unit) this turn, then pairs it with pilot “Amuro Ray” (name or trait match for link). currentPlayer =
    A, phase = MAIN_PHASE.
  - Action: Trigger the pairing via normal play flow so CardPlayExecutor runs.
  - Expect: isOnLink true in placement result, unit.canAttackOnPlayTurn === true, and the unit can declare an attack this same turn.
  - Negative check: pair ST01-001 with a non‑matching pilot; expect canAttackOnPlayTurn stays false and attack is rejected this turn.
