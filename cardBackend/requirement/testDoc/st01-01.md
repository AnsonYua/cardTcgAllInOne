
  1. Pair AP boost applies on your turn

  - Setup: Player A has ST01-001 paired with any pilot + another unit. currentPlayer = A, phase = MAIN_PHASE.
  - Action: Load `st01-001/pair_ap_boost_turn.json`, use the API to play Amuro and pair with ST01-001, then inspect
    `gameEnv` unit stats (no manual `processAllContinuousEffects(...)` call).
  - Expect: All Player A units show `continueModifyAP: +1` in `gameEnv` after the play action. Player B units have no
    `continueModifyAP` change.

  2. Pair AP boost only on your turn

  - Setup: Same units and hand as case 1, but currentPlayer = B, phase = MAIN_PHASE.
  - Action: Load `ST01-001/pair_ap_boost_opponent_turn.json` (A has ST01-001 in slot1, GM in slot2, Amuro in hand),
    use the API to play Amuro and pair with ST01-001, then end Player A's turn via API and inspect `gameEnv` unit stats
    (no manual `processAllContinuousEffects(...)` call).
  - Expect: No AP boost on A units when it is not A's turn (`continueModifyAP` remains 0 or unset).

  3. Repair 2 triggers at end of your turn

  - Setup: Player A has ST01-001 with damageReceived >= 1. currentPlayer = A, phase = MAIN_PHASE.
  - Action: Load `ST01-001/repair_end_turn.json` (A has ST01-001 in slot1 with damageReceived 1, GM in slot2),
    then call `POST /api/game/player/endTurn` to trigger END_PHASE SBA processing via normal game flow (no manual
    `processAllContinuousEffects(...)` call).
  - Expect: Damage reduced by 2, or to 0 if damageReceived < 2 after SBA completes.

  4. Repair does not trigger on opponent’s end

  - Setup: Same damaged unit, but currentPlayer = B, phase = MAIN_PHASE.
  - Action: Load `ST01-001/repair_end_opponent_turn.json` (A has ST01-001 in slot1 with damageReceived 1, GM in slot2),
    then call `POST /api/game/player/endTurn` to trigger END_PHASE SBA processing via normal game flow (no manual
    `processAllContinuousEffects(...)` call).
  - Expect: No heal on A unit (damageReceived unchanged).

  5. AP boost removed after source unit destroyed

  - Setup: Paired ST01-001 + another unit, currentPlayer = A, phase = MAIN_PHASE.
  - Action: Load `ST01-001/pair_ap_boost_destroy_source.json` (A has ST01-001 in slot1, GM in slot2, Amuro in hand,
    B has ST01-006 in slot1 paired with Suletta and both are rested), use the API to play Amuro and pair with ST01-001
    (confirm boost), then destroy the paired unit via battle using `POST /api/game/player/playerAction`
    (e.g. `attackUnit`, followed by `resolveBattle`/`confirmBattle` if needed) through normal game flow.
  - Expect: No AP boost remains on A units after the source unit is destroyed.

  
  6. Link allows immediate attack

  - Setup: Player A plays ST01-001 (unit) this turn, then pairs it with pilot “Amuro Ray” (name or trait match for link).
    currentPlayer = A, phase = MAIN_PHASE.
  - Action: Load `ST01-001/link_immediate_attack.json` (A has ST01-001 + Amuro in hand and enough energy, B has a unit in
    slot1), use the API to play ST01-001 (unit) and then play Amuro as pilot to pair via normal play flow so
    CardPlayExecutor runs, then attempt an attack using `POST /api/game/player/playerAction` with
    `actionType: attackUnit` and the attacker/target carduids.
  - Expect: unit `canAttackOnPlayTurn === true` in `gameEnv`, and the `attackUnit` action succeeds this same turn.
  - Negative check: pair ST01-001 with a non‑matching pilot via the same flow; expect `canAttackOnPlayTurn === false`
    and the `attackUnit` action is rejected this turn.
