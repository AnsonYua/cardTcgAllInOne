
  1. Pairing rests a single valid enemy unit

  - Setup: Player A has ST01-001 in slot1, ST01-010 (Amuro Ray) in hand, and 2 energy. Player B has ST01-005 in slot1.
    currentPlayer = A, phase = MAIN_PHASE.
  - Action: Load `ST01-010/pair_rest_single_target.json` (A has ST01-001 in slot1, Amuro in hand; B has ST01-005 in slot1),
    use the API to play Amuro as a pilot pairing with ST01-001.
  - Expect: The enemy unit in slot1 becomes rested, and the pilot is attached to ST01-001.

  2. Pairing triggers target selection when multiple valid targets exist

  - Setup: Player A has ST01-001 in slot1, Amuro in hand, and 2 energy. Player B has ST01-005 in slot1 and ST01-009 in
    slot2 (both HP <= 5). currentPlayer = A, phase = MAIN_PHASE.
  - Action: Load `ST01-010/pair_rest_multiple_targets.json` (A has ST01-001 in slot1, Amuro in hand; B has ST01-005 in slot1
    and ST01-009 in slot2), use the API to play Amuro as a pilot.
  - Expect: The response indicates a target selection flow is required and provides an `eventId`.
  - Action: Call `POST /api/game/player/confirmTargetChoice` with one selected target (`carduid`, `zone`, `playerId`),
    then inspect `gameEnv`.
  - Expect: Exactly one chosen enemy unit becomes rested, and the pilot is attached to ST01-001.

  3. Pairing does nothing when no valid targets exist

  - Setup: Player A has ST01-001 in slot1, Amuro in hand, and 2 energy. Player B has no units in play.
    currentPlayer = A, phase = MAIN_PHASE.
  - Action: Load `ST01-010/pair_rest_no_target.json` (A has ST01-001 in slot1, Amuro in hand; B has no units), use the API
    to play Amuro as a pilot pairing with ST01-001, then inspect `gameEnv`.
  - Expect: No target selection is required and no enemy unit becomes rested.

  4. Burst adds Amuro to hand when revealed from shield

  - Setup: Player A has ST01-010 in shield area. Player B can attack Player A’s shield. currentPlayer = B,
    phase = ATTACK_PHASE.
  - Action: Load a scenario where B declares a shield attack against A and reveals ST01-010 from A’s shield,
    then resolve the burst choice via `POST /api/game/player/confirmBurstChoice`.
  - Expect: ST01-010 moves to A’s hand instead of trash and the shield count decreases by 1.
