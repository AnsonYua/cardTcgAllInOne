
  1. Main ability heals a friendly unit by 3

  - Setup: Player A has ST01-013 in hand and 1 energy. A unit in slot1 has damageReceived = 2. currentPlayer = A,
    phase = MAIN_PHASE.
  - Action: Load `ST01-013/main_heal_friendly.json` (A has ST01-013 in hand; A has ST01-001 in slot1 with damage),
    use the API to play ST01-013 as a command, then activate its Main ability to choose the damaged unit.
  - Expect: The unit in slot1 recovers 3 HP (damageReceived reduced by 3, minimum 0).

  2. Main ability at full HP does not exceed max HP

  - Setup: Player A has ST01-013 in hand and 1 energy. A unit in slot1 is at full HP. currentPlayer = A,
    phase = MAIN_PHASE.
  - Action: Load `ST01-013/main_heal_at_full_hp.json` (A has ST01-013 in hand; A has ST01-001 in slot1 with no damage),
    use the API to play ST01-013 as a command, then activate its Main ability to choose the unit.
  - Expect: The unit remains at full HP (damageReceived stays 0).

  - Action: Load `ST01-013/play_as_pilot.json` (A has ST01-001 in slot1 and ST01-013 in hand), use the API to play

  - Expect: ST01-013 is attached as a pilot in slot1 (playedAs pilot) and is removed from hand; no heal effect is
