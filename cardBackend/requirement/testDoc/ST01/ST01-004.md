
  1. Deploy rests low-HP enemy unit

  - Setup: Player A has ST01-004 in hand and 2 energy, Player B has a unit with HP <= 2 in slot1. currentPlayer = A,
    phase = MAIN_PHASE.
  - Action: Load `ST01-004/deploy_rest_low_hp.json` (A has ST01-004 in hand, B has ST01-005 in slot1), use the API to
    play ST01-004 as a unit, then inspect `gameEnv`.
  - Expect: Player B slot1 unit isRested becomes true, and ST01-004 is placed in an A slot.

  2. Deploy does nothing when no valid target exists

  - Setup: Player A has ST01-004 in hand and 2 energy, Player B has only units with HP > 2. currentPlayer = A,
    phase = MAIN_PHASE.
  - Action: Load `ST01-004/deploy_rest_no_target.json` (A has ST01-004 in hand, B has ST01-001 in slot1), use the API to
    play ST01-004 as a unit, then inspect `gameEnv`.
  - Expect: No enemy unit is rested, and ST01-004 is placed in an A slot.

  3. Deploy triggers target selection when multiple valid targets exist

  - Setup: Player A has ST01-004 in hand and 2 energy, Player B has two units with HP <= 2 in slot1 and slot2.
    currentPlayer = A, phase = MAIN_PHASE.
  - Action: Load `ST01-004/deploy_rest_multiple_targets.json` (A has ST01-004 in hand, B has ST01-005 in slot1 and slot2),
    use the API to play ST01-004 as a unit.
  - Expect: The response indicates a target selection flow is required and provides an `eventId`.
  - Action: Call `POST /api/game/player/confirmTargetChoice` with one selected target (`carduid`, `zone`, `playerId`) to
    resolve the effect, then inspect `gameEnv`.
  - Expect: Exactly one chosen unit becomes rested, and ST01-004 is placed in an A slot.
