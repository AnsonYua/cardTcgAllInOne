
  1. Breach hits base when defender has a base

  - Setup: Player A has ST02-001 in slot1 with enough AP to destroy a target. Player B has a base in play and a unit in slot1 with low HP. currentPlayer = A, phase = MAIN_PHASE.
  - Action: Player A attacks B's unit and destroys it via normal battle flow.
  - Expect: Breach 5 triggers after the destroy. B's base takes 5 damage (damageReceived +5). If base HP is reduced to 0, it is destroyed.

  2. Breach removes 1 shield when no base is in play

  - Setup: Player B has no base, but has at least 1 shield card. Player A can destroy a B unit in battle. currentPlayer = A, phase = MAIN_PHASE.
  - Action: Player A destroys B's unit with ST02-001 in battle.
  - Expect: Breach 5 triggers and removes exactly 1 shield card from B's shield area, regardless of damage value.

  3. Breach with no base and no shields does not end the game

  - Setup: Player B has no base and no shields. Player A can destroy a B unit in battle. currentPlayer = A, phase = MAIN_PHASE.
  - Action: Player A destroys B's unit with ST02-001 in battle.
  - Expect: Breach 5 is ignored because there is no base and no shields. The game does not end.

  4. Attack can target active enemy unit with level <= 4

  - Setup: Player B has 2 active units: a Lv.3 unit (valid target) and a Lv.5 unit (invalid target). Player A has ST02-001 ready to attack. currentPlayer = A, phase = MAIN_PHASE.
  - Action: Player A declares an attack targeting the active Lv.3 unit.
  - Expect: Attack is allowed even though the target is active (because Lv.3 <= 4).

  5. Attack cannot target active enemy unit with level > 4

  - Setup: Same as above: Player B has an active Lv.5 unit available as a potential target. Player A has ST02-001 ready to attack. currentPlayer = A, phase = MAIN_PHASE.
  - Action: Player A declares an attack targeting the active Lv.5 unit.
  - Expect: Attack is rejected because the target exceeds level 4.
