
  1. Pairing applies AP-3 to a single valid enemy unit

  - Setup: Player A has ST01-006 in slot1, Suletta Mercury in hand, and 4 energy. Player B has ST01-005 in slot1.
    currentPlayer = A, phase = MAIN_PHASE.
  - Action: Load `ST01-006/pair_ap_reduction_single_target.json` (A has ST01-006 in slot1, Suletta in hand; B has
    ST01-005 in slot1), use the API to play Suletta as a pilot pairing with ST01-006.
  - Expect: The enemy unit in slot1 has `modifyAP: -3` (or total AP reduced by 3) for the turn, and pairing is established.

  2. Pairing triggers target selection when multiple valid targets exist

  - Setup: Player A has ST01-006 in slot1, Suletta in hand, and 4 energy. Player B has ST01-005 in slot1 and ST01-001
    in slot2 (both level <= 5). currentPlayer = A, phase = MAIN_PHASE.
  - Action: Load `ST01-006/pair_ap_reduction_multiple_targets.json` (A has ST01-006 in slot1, Suletta in hand; B has
    ST01-005 in slot1 and ST01-001 in slot2), use the API to play Suletta as a pilot.
  - Expect: The response indicates a target selection flow is required and provides an `eventId`.
  - Action: Call `POST /api/game/player/confirmTargetChoice` with one selected target (`carduid`, `zone`, `playerId`),
    then inspect `gameEnv`.
  - Expect: Exactly one chosen unit has `modifyAP: -3` (or total AP reduced by 3), and pairing is established.

  3. Pairing does nothing when no valid targets exist

  - Setup: Player A has ST01-006 in slot1, Suletta in hand, and 4 energy. Player B has no units in play.
    currentPlayer = A, phase = MAIN_PHASE.
  - Action: Load `ST01-006/pair_ap_reduction_no_target.json` (A has ST01-006 in slot1, Suletta in hand; B has no units),
    use the API to play Suletta as a pilot pairing with ST01-006, then inspect `gameEnv`.
  - Expect: No target selection is required and no enemy unit has `modifyAP` applied.

  4. AP reduction expires at end of turn

  - Setup: Player A has ST01-006 in slot1, Suletta in hand, and 4 energy. Player B has ST01-005 in slot1.
    currentPlayer = A, phase = MAIN_PHASE.
  - Action: Load `ST01-006/pair_ap_reduction_end_turn.json` (A has ST01-006 in slot1, Suletta in hand; B has ST01-005
    in slot1), use the API to play Suletta as a pilot pairing with ST01-006.
  - Expect: The enemy unit in slot1 has `modifyAP: -3` (or total AP reduced by 3) for the turn.
  - Action: Call `POST /api/game/player/endTurn` for Player A, then inspect `gameEnv`.
  - Expect: The temporary AP reduction is cleared (`modifyAP` removed or 0) on the enemy unit.

  5. AP reduction persists after ST01-006 is destroyed in the same turn

  - Setup: Player A has ST01-006 in slot1, Suletta in hand, and 4 energy. Player B has ST01-005 in slot1 and a unit
    that can destroy ST01-006 in battle. currentPlayer = A, phase = MAIN_PHASE.
  - Action: Load a scenario where A can pair ST01-006 and B can attack; use the API to play Suletta as a pilot pairing
    with ST01-006.
  - Expect: The chosen enemy unit has `modifyAP: -3` (or total AP reduced by 3) for the turn.
  - Action: Use `POST /api/game/player/playerAction` to destroy ST01-006 via battle in the same turn, then inspect
    `gameEnv`.
  - Expect: The AP reduction on the chosen enemy unit remains until end of turn, even though ST01-006 is destroyed.
