
  1. Main ability damages a rested enemy unit

  - Setup: Player A has ST01-012 in hand and 1 energy. Player B has a rested unit in slot1. currentPlayer = A,
    phase = MAIN_PHASE.
  - Action: Load `ST01-012/main_damage_rested.json` (A has ST01-012 in hand; B has rested ST01-005 in slot1), use the API
    to play ST01-012 as a command and resolve its Main effect.
  - Expect: Player B slot1 unit takes 1 damage (`damageReceived` +1 or current HP reduced by 1).

  2. Main ability has no valid target when all enemy units are active

  - Setup: Player A has ST01-012 in hand and 1 energy. Player B has only active units. currentPlayer = A,
    phase = MAIN_PHASE.
  - Action: Load `ST01-012/main_damage_no_rested.json` (A has ST01-012 in hand; B has active ST01-005 in slot1), use the
    API to play ST01-012 as a command and resolve its Main effect.
  - Expect: The command play fails because there is no valid rested target; ST01-012 remains in hand and no enemy unit
    takes damage.

  3. Command can be played as a pilot (Hayato designation)

  - Setup: Player A has ST01-012 in hand, a unit in slot1, and 1 energy. currentPlayer = A, phase = MAIN_PHASE.
  - Action: Load `ST01-012/play_as_pilot.json` (A has ST01-006 in slot1 and ST01-012 in hand), use the API to play
    ST01-012 as a pilot targeting the slot1 unit.
  - Expect: ST01-012 is attached as a pilot in slot1 (playedAs pilot) and is removed from hand; no damage effect is
    executed on play.
